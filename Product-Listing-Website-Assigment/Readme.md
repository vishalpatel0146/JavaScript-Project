# Jabronic – My Product Store

## About the Project

Jabronic is a responsive product store website developed as part of my web development assignment. It displays product information in an organized card layout, including product images, names, descriptions, prices, discounts, ratings, categories, and stock availability.

The main purpose of this project was to practice HTML, CSS, Bootstrap, and JavaScript by building a product listing page.

## Features

- Responsive product grid layout.
- Dynamic product cards generated using JavaScript.
- Product images and descriptions.
- Discounted prices and original prices.
- Discount percentage and product ratings.
- Product categories and stock information.
- Responsive navigation bar and footer.
- Hover effects and responsive styling.

## Technologies Used

- HTML5 – To structure the webpage.
- CSS3 – To style the product cards and page layout.
- Bootstrap 5 – To create a responsive layout and navigation bar.
- JavaScript – To display product data dynamically and calculate discounted prices.
- Remix Icon – To display icons.

## What I Learned from This Assignment

While working on this assignment, I learned how to:

- Structure a webpage using HTML.
- Apply CSS styling and hover effects.
- Use Bootstrap grid classes to create responsive layouts.
- Select HTML elements using `document.getElementById()`.
- Work with arrays of objects in JavaScript.
- Use `forEach()` to iterate through product data.
- Access object properties such as title, price, rating, and category.
- Calculate discounted prices using JavaScript.
- Use template literals to insert dynamic data into HTML.
- Generate product cards dynamically using `innerHTML`.
- Connect HTML, CSS, and JavaScript in a single project.

This assignment helped me understand how JavaScript can be used to display data dynamically on a webpage.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Make sure you have an internet connection to load Bootstrap, Remix Icon, and the externally hosted product images.
