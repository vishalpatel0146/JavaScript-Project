# Loop-Based Programs Assignment

This repository contains loop-based programming assignments implemented using **JavaScript** and **TypeScript**.

The programs are created for practicing loops, conditions, mathematical logic, and basic programming problem-solving.

## 📚 Versions

This assignment has been implemented twice:

- 🟨 JavaScript
- 🔷 TypeScript

## 🛠️ Technologies Used

- HTML5
- JavaScript
- TypeScript
- VS Code
