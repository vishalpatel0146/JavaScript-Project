## ▶️ How to Run

### JavaScript

1. Open the JavaScript project.
2. Open `index.html` in a web browser.
3. The JavaScript programs will run through the HTML page.
4. The output can be viewed directly on the web page.

### TypeScript

1. Open the TypeScript project.
2. Write or modify the code in the `.ts` file.
3. Compile the TypeScript file into JavaScript using the TypeScript compiler.
4. Open `index.html` in a web browser.
5. The compiled JavaScript file will execute the programs.

## 💻 Example

### Reverse a Number

Given number:

```text
3215
```

Output:

```text
5123
```

The program uses a loop to extract each digit and build the reversed number.

### Palindrome Number

Given number:

```text
121
```

Output:

```text
121 is a Palindrome Number
```

A number is a palindrome when its reverse is the same as the original number.
