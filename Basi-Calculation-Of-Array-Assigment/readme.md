# TypeScript Assignment – Arrays and Strings

## About This Assignment
This assignment helped me practice the fundamentals of TypeScript by solving 15 programming questions based on arrays, strings, loops, functions, and DOM manipulation.

## Topics I Learned

### 1. Array Methods
- `join()` – Convert array elements into a string with a separator.
- `slice()` – Extract a portion of an array.
- `push()` – Add a new element to an array.
- `filter()` – Filter array elements based on a condition.
- `map()` – Create a new array by transforming elements.
- `sort()` – Sort array elements in ascending and descending order.
- `reverse()` – Reverse the order of array elements.
- `includes()` – Check whether an array contains a particular value.
- `forEach()` – Execute a function for each array element.

### 2. Loops and Functions
- Used `for` loops and `forEach()` to calculate the sum of array elements.
- Created functions to find the maximum and minimum values in an array.
- Used conditional statements to compare values.

### 3. String Methods
- `charAt()` – Access a character at a specific index.
- `charCodeAt()` – Get the numeric character code.
- `toUpperCase()` – Convert a string to uppercase.
- `toLowerCase()` – Convert a string to lowercase.
- `replaceAll()` – Replace all occurrences of a substring.
- `split()` – Convert a string into an array.
- `length` – Find the number of characters in a string.

### 4. TypeScript Fundamentals
- Declared variables using `let`.
- Used type annotations such as `string`, `number`, and `boolean`.
- Created typed arrays such as `string[]` and `number[]`.
- Used union types such as `(string | number)[]`.
- Worked with function parameters and return values.

### 5. DOM Manipulation
- Used `document.getElementById()` to access HTML elements.
- Displayed output using `innerText`.
- Used `String()` to convert values into strings.
- Used the non-null assertion operator (`!`) with DOM elements.

### 6. Array Operations
- Printed array elements and selected elements.
- Calculated the sum of array elements.
- Found maximum and minimum values.
- Removed negative numbers from an array.
- Calculated the square of each number.
- Sorted and reversed arrays.
- Checked whether a value exists in an array.

## Assignment Summary

- **Total Questions:** 15
- **Language:** TypeScript
- **Concepts Practiced:** Arrays, Strings, Loops, Functions, Type Annotations, and DOM Manipulation.
